     ┌─────────────────────────────────────────────────────────────┐
     │ 3D Canvas 背景 (微暗化处理 brightness 0.7, 突出板书)        │

     │   ┌─────────────────────────────────────────────────────┐   │

     │   ├─────────────────────────────────────────────────────┤   │
     │   │  • AB 沿 y 轴方向:   \vec{AB} = (0, y_B, 0)         │   │
     │   │  • 空间向量分解:     \vec{CD} = (\Delta x, y_D - y_C, \Delta z) │
     │   │  • 数量积正交条件:   \vec{AB} \cdot \vec{CD} = y_B(y_D - y_C) = 0 │
     │   │                                                     │   │
     │   │  ⟹ y_D = y_C  (两点必须共截面，O₁ 与 O₂ 重合)     │   │

     └─────────────────────────────────────────────────────────────┘
